# Mini-desafios de React — UNIESP

Este repositório contém a resolução dos **12 mini-desafios de React** da disciplina, contemplando as Partes 1 e 2 do material proposto.

O projeto foi desenvolvido com **React + Vite**, utilizando conceitos fundamentais como componentes, JSX, eventos, estados, props, renderização de listas, CSS Modules, React Router, useEffect, Axios e consumo de uma API fake com JSON Server.

---

## Tecnologias utilizadas

* React
* Vite
* JavaScript
* CSS Modules
* React Router
* Axios
* JSON Server

---

## Como rodar o projeto

### 1. Instalar as dependências

```bash
npm install
```

### 2. Iniciar o projeto React

```bash
npm run dev
```

### 3. Iniciar o back-end fake

Em outro terminal, execute:

```bash
npm run server
```

### 4. Acessar no navegador

Projeto React:

```bash
http://localhost:5173
```

API fake de filmes:

```bash
http://localhost:3001/filmes
```

## Mini-desafios desenvolvidos

* **MeuPerfil** — criação de componente simples utilizando JSX.
* **BotaoAlerta** — utilização de evento `onClick`.
* **TrocaTexto** — uso do hook `useState`.
* **LogoUniesp** — importação e exibição de imagens da pasta `public`.
* **Filme e ListaDeFilmes** — uso de `props` e renderização com `.map()`.
* **MaiorDeIdade** — renderização condicional com operador ternário e Fragments.
* **CartaoDestaque** — estilização utilizando CSS Modules.
* **EcoTexto** — input controlado com `onChange`.
* **Site com 2 páginas** — navegação utilizando React Router.
* **DataDeAgora** — uso do hook `useEffect`.
* **API de filmes em 5 minutos** — criação de API fake com JSON Server.
* **ListaDeFilmes com Axios** — consumo da API fake utilizando Axios.

O objetivo deste projeto é praticar os principais conceitos iniciais do React, aplicando cada conteúdo em pequenos desafios práticos e progressivos.
